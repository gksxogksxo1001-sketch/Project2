# 🎰 LUCKY LAB 30s: 30초 확률 아케이드 요구사항 명세서 (PRD)

> **문서 버전**: V3.0 (과제 1~5 체크리스트 100% 충족판)  
> **배포 URL**: [https://gksxogksxo1001-sketch.github.io/Project2/](https://gksxogksxo1001-sketch.github.io/Project2/)  
> **아키텍처**: Zero-Backend Vanilla Single-Page Application

---

## 1. 프로젝트 개요
- **목표**: 로그인 없이 브라우저 단독으로 실행되며, 10,000 기본 포인트를 바탕으로 30초 주기(`10s 베팅 -> 10s 결과 공개 -> 5s 정산`)로 직관과 운을 시험하는 모던 확률 아케이드 게임.
- **게임 3종**: 
  1. 🎲 **다이스 홀짝**: 쉐이커 컵 오픈 후 두 주사위의 합(홀/짝) 판정.
  2. 🃏 **하이로우 카드**: 기준 카드 대비 3D 플립된 다음 카드의 대소(High/Low) 비교.
  3. 🏁 **스피드 레이스**: 4마리 주자의 실시간 캔버스 2D 추월 레이스.

## 2. 과제 체크리스트 1~5 전 항목 검증 체계

### [카드 1] 30초 핵심 규칙 (T02-C01 ~ C09)
- **T02-C01 (무로그인)**: 계정 생성, 로그인, OAuth, 비밀번호 없이 시크릿 창에서 1초 만에 즉시 실행.
- **T02-C03 ~ C06 (규칙/조작/상태)**: 상단 실시간 타이머 바, 라운드 번호, 현재 포인트, 베팅 타겟 상시 동기화.
- **T02-C07 ~ C09 (라이프사이클)**: `[베팅 10초] -> [결과 공개 10초] -> [정답 확인 및 정산 5초]` 루프 완주 후 다음 라운드 자동 초기화.

### [카드 2] PC 경계 검사 (T02-C10 ~ C17)
- **T02-C10, C11 (해상도)**: `1366×768` 및 `1920×1080` 해상도에서 가로 스크롤 0건, 조작 영역 잘림 0건.
- **T02-C12 (연타 방어)**: 300ms Throttle 및 `isActionLocked` 플래그로 1초 10회 연속 클릭 시 1회만 인정.
- **T02-C13 ~ C15 (포커스 & 일시정지)**: 수동 [일시정지] 버튼 및 `visibilitychange` 탭 이탈 시 타이머 동기화 보호.
- **T02-C16, C17 (10분 연속 실행)**: 10분 연속 실행 시 콘솔 빨간 에러 0건, `cancelAnimationFrame` 메모리 클린업.

### [카드 3] 10회 전후 난이도 선택 (T02-C18 ~ C21)
- **T02-C18 ~ C20 (단일 난이도 값 비교)**: 카지노 수수료율(House Edge) 값 **단 하나만** 변경하여 10회씩 비교.
  - **1~10회 (스탠다드 모드)**: 수수료 5%, 기본 배당 1.95x ➔ 안정적인 플레이.
  - **11~20회 (챌린지 모드)**: 수수료 15%, 잭팟 배당 x3 (특수 룰 7 하우스 회수) ➔ 고수익·고위험 변동형.
- **T02-C21 (최종 난이도 선택 이유)**: 챌린지 모드는 잭팟 배당은 높으나 장기 수수료 누적으로 파산율이 급증하므로, 30초 루프의 지속 가능성과 초심자 접근성을 위해 기본 권장값으로 **'스탠다드 모드(수수료 5%)'**를 최종 선택.

### [카드 4] 저장과 손상 복구 (T02-C22 ~ C25)
- **T02-C22 (새 판 초기화)**: 매 라운드 시작 시 현재 베팅 포인트, 선택 타겟, 확정 플래그는 0으로 안전 초기화.
- **T02-C23 (보존 기록 유지)**: 보유 포인트 및 최근 20회 히스토리는 브라우저 새로고침(F5) 뒤에도 완벽 유지.
- **T02-C24, C25 (빈 값/손상 값 자가치유)**:
  - `localStorage`의 포인트 값이 `null`, `NaN`, 음수(`-9999`)로 변조되어도 기본 `10,000 포인트`로 자가 복구.

### [카드 5] 효과와 선택권 (T02-C26 ~ C31)
- **T02-C26 (선택 사건 실행)**: 승리/패배 및 라운드 정산 시점에만 사운드 및 효과 발동.
- **T02-C27 (음소거 및 모션 줄이기)**: 
  - 상단 헤더의 `[🔇 음소거]` 토글 시 오디오 즉시 차단(0ms).
  - 상단 헤더의 `[✨ 모션 줄이기]` 토글 시 Canvas Confetti 꽃가루 폭죽 즉시 차단.
- **T02-C28, C29 (개인정보 및 비밀값)**: 이메일, 패스워드, API Key 등 노출 0건.

## 3. 과제 제출 증거 템플릿

### 3.1. 짧은 확인 방법 (4줄)
1. **어디로 가나요**: GitHub Pages 배포 사이트 (`https://gksxogksxo1001-sketch.github.io/Project2/`)
2. **3단계 이내 무엇을 하나요**: 
   - ① 타겟(`홀(ODD)` 버튼) 클릭 
   - ② 하단 `[베팅 확정하기]` 클릭 
   - ③ 10초 후 주사위 컵 오픈 및 정산 관찰
3. **무엇이 보이면 통과인가요**: 30초 내 주사위 결과 오픈 및 상단 포인트 변동, 하단 20회 테이블에 1행 즉시 추가 완료.
4. **안 될 때 무엇이 보이나요**: 베팅 확정을 누르지 않으면 포인트 차감 없이 관전 모드로 안전 진행되며 콘솔 에러가 발생하지 않음.

### 3.2. AI와 나의 판단 (3줄)
1. **AI에게 맡긴 일**: 30초 타이머 상태머신, 로컬스토리지 음수/NaN 자가치유 알고리즘, Canvas 2D 경마 물리 엔진 및 CSS 3D 카드 플립 연출 구현.
2. **학생이 직접 판단한 일**: 불법 사설 도박 느낌을 배제한 모던 슬레이트 테마 선정, 10-10-5 황금 템포 배분, 그리고 1~10회(스탠다드) vs 11~20회(챌린지) 단일 난이도 비교 체계 확립.
3. **AI 제안을 따르지 않은 일(이유)**: 복잡한 웹소켓 멀티플레이 방 만들기 제안을 배제함. 계정 생성 없는 1초 즉시 실행(T02-C01)과 네트워크 핑 지연 없는 30초 루프 완주(T02-C07)를 보장하기 위해 브라우저 단독 Zero-Backend 구조를 고수함.
