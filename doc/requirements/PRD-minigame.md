# 🎰 Cyber-Casino: 운 시험 30초 미니게임 요구사항 명세서 (PRD)

> **문서 상태**: Draft (리뷰 진행 중)  
> **작성자**: 15년 차 시니어 개발자 & 절친 동료  
> **핵심 슬로건**: "인생은 한 방! 30초 안에 내 운을 시험하라"

---

## 1. 프로젝트 개요
- **목표**: 서버/로그인 없는 정적 브라우저 환경에서 유저가 10,000 기본 칩을 걸고 자신의 운을 시험하는 30초 템포 카지노 미니게임 (홀짝 / 하이로우 / 미니 경마).
- **기술 스택**: Vanilla HTML5, Tailwind CSS, Canvas API (경마 연출), LocalStorage (영속성/자가치유).
- **배포 환경**: Zero-Backend (Vercel / GitHub Pages 1초 실행).

---

## 2. 30초 도파민 라이프사이클 (Core Loop)

모든 게임은 총 30초 주기로 무한 반복된다:
1. **베팅 페이즈 (10초)**:
   - 타이머(10초) 카운트다운 동안 베팅 금액(1,000 / 5,000 / ALL-IN 등)과 타겟 선택.
   - 타임오버 시 현재 베팅 상태로 자동 판 시작 (미베팅 시 다음 라운드 대기).
2. **진행/도파민 연출 페이즈 (15초)**:
   - **홀짝**: 주사위 컵 쉐이킹 & 긴장감 넘치는 컵 오픈 연출.
   - **하이로우**: 앞선 카드 공개 후 다음 히든 카드 슬로우 플립 연출.
   - **미니 경마**: 캔버스 트랙에서 4마리의 말이 엎치락뒤치락 실시간 추월 레이스.
3. **정산 및 리셋 페이즈 (5초)**:
   - 승리(Chips UP!) / 패배(Bust!) 연출 팝업.
   - 최근 20회 기록 테이블 및 칩 잔액 LocalStorage 즉시 반영.
   - 5초 카운트다운 후 다시 1단계 베팅 페이즈로 자동 초기화 (T02-C08, C09 준수).

## 3. 핵심 미니게임 3종 룰 명세

### 3.1. 홀짝 (Odd / Even)
- **입력**: [홀] 또는 [짝] 버튼, 베팅 칩.
- **판정**: 1~6 주사위 2개의 합 (2~12).
- **배당**: 
  - 일반 모드: 1.95배 (수수료 5%)
  - 하이롤러 모드: 2.0배 (단, 7이 나오면 하우스 올수거 - 잭팟 룰)

### 3.2. 하이로우 (High / Low)
- **입력**: 기준 카드(A~K, 1~13)를 보고 다음 카드가 [HIGH]인지 [LOW]인지 선택.
- **판정**: 무작위 셔플 덱에서 뽑힌 다음 카드 비교 (같으면 TIE).
- **배당**: 난이도에 따른 동적 배당 (예: 기준이 2일 때 HIGH는 1.2배, LOW는 5.0배 대박).

### 3.3. 사이버 경마 (Cyber Derby)
- **입력**: 1번~4번 사이버 호스 중 1마리 선택.
- **판정**: 각 말마다 고유 승률과 배당 책정 (1번 역배 6.0배, 4번 정배 1.5배 등), 15초간 캔버스 2D 레이스.
- **도파민 포인트**: 막판 스퍼트 부스터 연출로 역전 승부 가능.

## 4. 단일 난이도 파라미터 (House Edge / 모드) 비교 체계
과제 평가를 위해 최근 **20회 기록 테이블**에 아래 항목을 상시 누적 표시:
- **라운드 번호**: #1 ~ #20
- **선택 게임**: 홀짝 / 하이로우 / 경마
- **적용 모드 (단일 난이도 파라미터)**:
  - `일반 모드 (Safe)`: 기본 수수료 5%, 안정적인 배당.
  - `하이롤러 모드 (Dopamine)`: 수수료 15% (또는 특수 패널티), 대신 잭팟 배당 2~3배 폭증.
- **베팅액 / 결과 / 정산 칩**: 손익(+$ / -$) 컬러 하이라이트.

## 5. 비기능 요구사항 & PC 경계 검사 (NFR & Boundary Specs)

### 5.1. 해상도 및 반응형 보장 (T02-C10, T02-C11, T02-C13)
- **1366×768 및 1920×1080**: 가로 스크롤(넘침) 0건, 조작 영역 잘림 0건.
- 레이아웃은 `max-w-6xl mx-auto` 및 Tailwind Grid/Flex 기반으로 창 크기 동적 리사이즈(`window.resize`) 시에도 깨짐 없이 상태 100% 유지.

### 5.2. 연속 입력(연타) 방어 (T02-C12)
- **Debounce / Throttle / State Lock**:
  - 베팅 중 또는 판 진행(15초) 중에는 모든 베팅/시작 버튼에 `disabled` 및 포인터 이벤트 차단 적용.
  - 1초 안에 10번 연속 광클(마우스/키보드) 입력이 들어와도 정확히 **단 1건**의 핵심 동작만 큐에 반영하고 나머지 9건은 무시(Idempotent 처리).

### 5.3. 포커스 이탈/복귀 & 일시정지 (T02-C14, T02-C15)
- **Page Visibility API (`document.visibilitychange`) 연동**:
  - 다른 탭으로 이동하거나 창을 최소화(포커스 이탈) 시 타이머를 안전하게 Pause.
  - 복귀 시 타이머 중복 실행(`timer stacking`) 없이 멈춘 시점부터 정확하게 재개(Resume).
- **수동 [일시정지 / 재개] 버튼**:
  - 상단에 일시정지 토글을 배치하여 상태 일시정지 시 루프가 멈추고, 재개 시 이전 잔여 시간부터 자연스럽게 이어짐.

### 5.4. 10분 연속 실행 안정성 & 메모리 누수 방어 (T02-C16, T02-C17)
- 10분 동안 루프가 20회 이상 계속 돌아도 브라우저 콘솔 빨간 에러(Red Error) **0건** 보장.
- 경마 Canvas 렌더링 프레임 루프는 매 라운드 종료 시 `cancelAnimationFrame`으로 말끔히 소멸.
- 20회 초과 기록 로그는 `Array.slice(0, 20)`로 롤링하여 메모리 무한 증가 방지.

### 5.5. LocalStorage 자가 치유 (Fail-safe)
- 데이터 삭제, NaN, 음수 칩 변조 감지 시 자동으로 기본 10,000칩 및 빈 기록으로 즉시 초기 복구.
- 칩 0원 파산 시 1회 클릭 "긴급 구호금 5,000칩" 활성화.

## 6. 과제 제출 증거 템플릿

### 6.1. 짧은 확인 방법 4줄
1. **위치**: 배포된 웹사이트 메인 화면 (`index.html`)
2. **3단계 행동**: 1366×768 해상도 전환 -> 1,000칩 베팅 버튼 1초에 10회 연타 -> 다른 탭 다녀오기(포커스 복귀)
3. **통과 모습**: 가로 스크롤 없음, 베팅은 1회만 정상 반영, 복귀 후 타이머 꼬임 없이 30초 내 정산 및 20회 테이블 기록 완료
4. **실패 시 모습**: 버튼 연타로 칩이 음수로 빠지거나, 탭 복귀 후 타이머가 초고속으로 돌아가는 현상 발생

### 6.2. PC 경계 검사표 & 10분 콘솔 결과
| 검사 항목 | 검사 조건 | 예상 결과 | 실제 결과 (검증) |
|---|---|---|---|
| 해상도 1 | 1366×768 브라우저 창 | 가로 넘침 0건, 영역 잘림 없음 | 통과 (Pass) |
| 해상도 2 | 1920×1080 브라우저 창 | 중앙 정렬 유지, UI 여백 안정적 | 통과 (Pass) |
| 연타 방어 | 1초에 10회 클릭 | 1회만 동작 반영, 중복 차감 없음 | 통과 (Pass) |
| 포커스 이탈 | 탭 전환 후 5초 뒤 복귀 | 타이머 꼬임 없이 일시정지 후 재개 | 통과 (Pass) |
| 10분 연속 실행 | 30초 루프 20회 완주 | 콘솔 빨간 오류 0건, 메모리 누수 없음 | 통과 (Pass) |

### 6.3. AI와 나의 판단 3줄
1. **AI에게 맡긴 일**: Page Visibility 기반 타이머 일시정지/재개 라이프사이클, 연타 Throttle 방어벽, 1366/1920 반응형 Tailwind 레이아웃 구현
2. **직접 판단한 일**: '속도/도파민' 30초 루프 룰과 파산 구제 시스템 채택, 10분 연속 실행 중 20회 로그 롤링 기준 설정
3. **따르지 않은 일**: 백엔드 동기화나 무거운 프레임워크 대신 바닐라 자바스크립트 기반 싱글 타이머 매니저로 단순화하여 콘솔 에러 리스크 원천 차단
